Description

Hello hello! I hope yall doing great!

It's my first mod so I'm really looking forward to your comments on this one At first, I was only doing it for myself, I'm a big Palariffle fan (sorry!) and I wanted my paladin to look like something else. I chose Omniknight with the Godhammer cosmetic set because I thought it would make it easier for me to take a dota character and import it to WC3. Stand 2 is a custom animation that I made (not perfect, but I'm still learning). I tried to make him do a ''holy rasengan''. Dissipate is also custom. Everything else is from Dota, for example Stand 3 is the taunt of Omniknight. I know some things are not perfect, like the portrait...but I can't find how to make it better by myself, so I'm really looking for constructive feedbacks.

This model uses Reforged MDX v1200 features.

To see it, use the 3D beta version!
