Description

Earlier I created a tutorial for how to merge the Succubus legs onto Jaina. After making the tutorial I thought it would be interesting to take the same file a few steps further to create a demonic version of the Reforged Jaina Model.

See if you, too, can learn from the tutorial and build off of what you know to make fun models!

Model is tagged as open source, feel free to credit me or modify the model or try to make it yourself starting from that tutorial, or whatever else you would like!

Edit: Fixed an issue where there was some geometry around her torso that did not fit correctly
