doodads\terrain\ashentree\ashentree...

For lordaeron trees:

doodads\terrain\lordaerontree\lordaerontree0.mdx
doodads\terrain\lordaerontree\lordaerontree0s.mdx
doodads\terrain\lordaerontree\lordaerontree...

For City use lordaeron trees as base:

doodads\terrain\cityscapetree\cityscapetree0.mdx
doodads\terrain\cityscapetree\cityscapetree0s.mdx
doodads\terrain\cityscapetree\cityscapetree...
